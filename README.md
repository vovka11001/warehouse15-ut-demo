# Склад 15 (Клеверенс) + 1С:Управление торговлей 11 — типовое развёртывание

Тестовое задание: поднять типовую связку «1С:УТ ↔ Mobile SMARTS: Склад 15 ↔ мобильный клиент», пройти один полный сценарий и показать, что данные ушли из 1С, обработались на стороне Клеверенса и вернулись обратно.

## Что развёрнуто

| Компонент | Версия |
|---|---|
| 1С:Предприятие (платформа, учебная версия) | [ВСТАВИТЬ: версия платформы из «О программе»] |
| Конфигурация «Управление торговлей», ред. 11 (демо-база) | 11.5.27.93 |
| Mobile SMARTS: Склад 15, редакция «Минимум» (сервер) | 4.0.2.53127 |
| Веб-панель Склада 15 | 2.0.8497 |
| Мобильный клиент Склада 15 (Android) | 4.0.2.53127 |
| Устройство | эмулятор Android (AVD, Pixel) без физического сканера |

Режим работы Склада 15: **демо** (без лицензии), документ ограничен тремя строками.

## Как развёрнуто

1. Установлена конфигурация УТ 11.5.27.93, создана демо-база.
2. Установщиком `WH15.InstallWizard` создана база «Склад 15, Минимум» на локальном сервере Mobile SMARTS, в мастере выбрана учётная система «1С:Предприятие 8».
3. В 1С подключена главная обработка Клеверенса (мастер «1C Exchange Setup»). Результат — экран «Setup complete».
4. Включён обмен через Интернет (шлюз Клеверенса).
5. Клиент Склада 15 установлен на Android-эмулятор из APK и подключён к серверу со страницы «Подключить устройство» веб-панели.

## Проверенный сценарий: приёмка по заказу поставщика

1. **Справочники.** В 1С: «Клеверенс» → «Обмен справочниками» → «Выгрузить все справочники». В клиенте (Browse Directories → Products) появилась номенклатура из демо-базы УТ.
2. **Заказ поставщику.** В УТ создан заказ ЧП00-000001 на 3 товара (кофе-машина «Универсал» — 2, мясорубка MOULINEX A 15 — 5, соковыжималка BINATONE JE 102 — 1), заказ проведён, статус «Подтверждён».
3. **Выгрузка на ТСД.** «Клеверенс» → «Обмен документами» → отмечен заказ → «Выгрузить из 1С». Сообщение: «На ТСД успешно выгружено 1 документов». В панели Склада 15 документ появился в разделе «Приёмка».
4. **Приёмка на терминале.** В клиенте «Receiving» открыт заказ, принято 2 / 5 / 1, итог «converged: 3 of 3», документ завершён (статус «Завершён» в панели).
5. **Возврат в 1С.** В «Обмене документами» документ из правой таблицы загружен кнопкой «Загрузить в 1С» в режиме «новый». В УТ создан документ «Приобретение товаров и услуг» на основании заказа с теми же 3 строками, документ проведён.

## Ограничения и особенности

- **Демо-режим Склада 15**: нет лицензии, лимит три строки в документе.
- **Платформа 1С** — учебная версия; демо-база УТ, не промышленная.
- **Редакция «Минимум»**: сценарий ограничен приёмкой, настройки бизнес-процессов остались по умолчанию.
- **Статус заказа.** Документ «Приобретение товаров и услуг» создаётся на основании заказа только при статусе «Подтверждён» или «Закрыт». С «Согласован» загрузка в 1С падает с ошибкой. Это правило типовой УТ.
- **Завершение на ТСД.** Строки попадают в документ 1С только после завершения приёмки на терминале; до этого форма документа открывается пустой.
- **Эмулятор вместо ТСД**: физического сканера нет, работа идёт на виртуальном устройстве.
- **Режим загрузки.** В окне «Выбор документа для загрузки» нужно оставлять «новый», иначе результат запишется поверх существующего документа.
- Онлайн-обмен и регламентный обмен документами не настраивались, использован ручной обмен.
- В журнале событий уровень детализации не менялся.
